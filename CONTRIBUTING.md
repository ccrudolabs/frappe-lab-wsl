# Contributing

Gracias por colaborar con este laboratorio.

## Reglas basicas

- Mantener el foco en Frappe/ERPNext, WSL, Docker y desarrollo local reproducible.
- No publicar secretos, backups ni datos reales.
- Documentar comandos, prerequisitos y decisiones tecnicas.
- Validar que los cambios no rompan la instalacion base.

## Flujo sugerido

1. Crear una rama descriptiva.
2. Agregar cambios acotados.
3. Documentar el escenario probado.
4. Abrir un pull request con resumen y pasos de validacion.
