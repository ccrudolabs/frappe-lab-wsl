# Security Policy

## Alcance

Este repositorio contiene material de laboratorio para Frappe/ERPNext, WSL, Docker y entornos de desarrollo.

## Informacion sensible

No se deben publicar:

- archivos `.env`,
- backups de sitios,
- bases de datos,
- tokens,
- claves SSH,
- contrasenas,
- logs con datos privados,
- datos de clientes o ambientes reales.

## Reporte

Si detectas informacion sensible o una vulnerabilidad, reportalo de forma privada por LinkedIn:

- https://www.linkedin.com/in/carloscrudo/

No abras issues publicos con secretos o datos privados.
